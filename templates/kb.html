Alimenter la base par import de documents

Soumettez un DUERP existant ou tout fichier listant des situations dangereuses :
• Excel (.xlsx/.xls) ou CSV — import direct, sans clé API : le fichier doit contenir des colonnes repérables (Risque, Situation dangereuse, F, G, M, Mesures, Actions). Les exports Excel de ce logiciel sont directement réutilisables.
